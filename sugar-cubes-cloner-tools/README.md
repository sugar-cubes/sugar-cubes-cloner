# Build tools of the cloner

An annotation processor, a Maven plugin and the Gradle plugin `io.github.sugar-cubes.cloner`, which add copy
constructors to the classes listed in `META-INF/sugar-cubes-cloner/copy-constructors`: the cloner creates their clones
by `new` and writes final fields directly.

See [Build tools](https://sugar-cubes.github.io/sugar-cubes-cloner/build-tools/) on the site of the project
(source: [docs/build-tools.md](../docs/build-tools.md)).
